Mode Edit Belum Disiapkan

Login Google butuh OAuth Client ID yang hanya bisa dibuat oleh pemilik spreadsheet. Sekali saja, sekitar 5 menit:

  1. Buka console.cloud.google.com → buat project baru.
  2. Menu APIs & Services → Library → cari Google Sheets API → Enable.
  3. OAuth consent screen → tipe External → isi nama aplikasi & email → di bagian Test users, tambahkan email bendahara.
  4. Credentials → Create Credentials → OAuth client ID → tipe Web application.
  5. Di Authorized JavaScript origins, isi alamat situs ini — misalnya http://localhost:8000.
  6. Salin Client ID, tempel ke file assets/js/config.js pada baris OAUTH_CLIENT_ID.
  7. Di config.js juga, isi ADMIN_EMAILS dengan email bendahara.
  8. Pastikan akun bendahara diberi akses Editor pada spreadsheet-nya.

Selama belum disiapkan, halaman ini tetap berfungsi normal dalam mode baca.
